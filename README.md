## Requisitos

- Conferir se o Node está instalado:

```
node -v
```

- Conferir se está instalado o npx:

```
npx - v
```

- Conferir se está instalado o GIT:

```
git -v
```

## Como rodar o projeto baixado

1. Baixar os arquivos do github e instalar na sua pasta selecionada

```
git clone https://github.com/msan-ufms/Controle-Financeiro.git <CAMINHO DA PASTA>

```

Exemplo:

```
git clone https://github.com/msan-ufms/Controle-Financeiro.git C:\Projetos\Projeto

```

2. Instalar Todas as dependências indicadas pelo package.json

```
npm install
```

Rodar o projeto React

```
npm run dev
```

Acessar no navegador a URL:

[http://localhost:5173/](http://localhost:5173/)

## Como enviar o projeto para o GiThub

Instalar o git

Disponível em

[GIt](https://git-scm.com/install/)

Acessar a plataforma [github](https://github.com/)

Criar um novo repositório

Inicializar um novo repositório Git.

```
git init
```

Adicionar todos os arquivos modificados no staging area - área de preparação.

```
git add .
```

Commit representa um conjunto de alterações

```
git commit -m "Base do Projeto"
```

```
git branch -M main
```

```
git remote add origin https://github.com/msan-ufms/React-Project.git
```

```
git push -u origin main
```
